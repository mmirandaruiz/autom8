Privacidad

Responsable del tratamiento: Autom8. Contacto: marcos@autom8.es.

Qué datos se recogen

Solo si escribes tú. El formulario de contacto pide nombre, correo y un mensaje. La calculadora, si pides el análisis, envía tu correo y el resultado que se muestra en pantalla.

Para qué

Para responder a esa solicitud. No se usan para publicidad ni se venden.

Quién los recibe

El envío lo hace Web3Forms, que entrega el mensaje a marcos@autom8.es. Las fuentes y la escena 3D se sirven desde este mismo sitio: el navegador no llama a Google Fonts ni a una red de anuncios.

Cuánto tiempo

El tiempo necesario para contestar y, si hay una conversación comercial, mientras dure esa relación. Puedes pedir que se borren antes.

Tus derechos

Puedes pedir acceso, rectificación, supresión, limitación u oposición escribiendo a marcos@autom8.es. También puedes reclamar ante la Agencia Española de Protección de Datos.
